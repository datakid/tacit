Stable release. Release build, signed outside GitHub.
- Added: the first file search shows "Indexing files… N found" with early results, and the file index refreshes when you open Tacit or Settings
- Added: quicklinks to a screen inside another app (pick the app, then the screen), a Settings explorer, custom intent quicklinks with a Try button, Legacy shortcut, and quicklink icons (standard, the app's icon, or letters)
- Added: when Tacit is the home app, a shortcut pinned from another app asks to be added to Tacit, and Remove from Tacit takes it out again
- Added: Compact is a dense row (48 dp, subtitle on the same line); contact buttons that don't fit a narrow screen move into a More button; screen reader labels for the letter strip and the drawer tabs
- Fixed: Home no longer crashes Tacit when the result list is empty; WhatsApp buttons and app icons follow installs, removals and updates; a pinned shortcut follows its quicklink's rename; Import asks first and then applies everything at once
- Changed: search skips items that cannot match, with the same results; app icons are drawn on a thread of their own; touching the Apps button draws the first icons before the drawer opens; file search and scans are faster; one refresh per burst of app events
- Changed: the file index is stored in a new format and rebuilds once after the update; quicklinks gain an icon column that older builds ignore; backup format 2 carries the icons and format 1 files still import
- Kept: the app drawer stays opt-in and off by default, with no Files tab (decision 85)
- Note: a phone with a beta build must uninstall it first (different signing key); export settings first. A phone on 1.0.0 updates in place.
- APK: debug +193,353 B, release +59,256 B (compared with 1.0.0)
- Tested: emulators Android 14, 15, 16; since 1.0.0 112 new device tests and 158 new unit tests; not tested on a phone
